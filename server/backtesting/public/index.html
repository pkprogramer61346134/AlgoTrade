4-Stage Trailing Stop Loss Rules

  • Initial Risk: Entry Spot \(\pm\) Risk Points (SL).
  • TR1 (1:1 Hit): Trailed to Cost-to-Cost (Entry Spot). Zero risk!
  • TR2 (1:2 Hit): Trailed to TR1 Target Level.
  • TR3 (1:3 Hit): Trailed to TR2 Target Level.
  • TR4 Target (1:4 Hit): Exit trade at full target 1:4 profit!
